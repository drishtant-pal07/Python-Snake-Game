# 🐍 Python Snake Game - A Classic Arcade Build

A fully functional classic Snake Game built to practice Python logic building and game development using **Pygame**.

### 🎨 Features:
- **Classic Gameplay:** Standard snake mechanics with scoring.
- **Retro Interface:** Clean, grid-based arcade look.
- **Score Tracking:** Real-time scoring and persistent high scores.
- **Responsive Controls:** Smooth movement and game speed.

### 🛠️ Tech Stack:
- **Python 3**
- **Pygame**
